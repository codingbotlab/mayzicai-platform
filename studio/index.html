Developer API

Local endpoints for integration tests. No API key or internet-facing service is configured.

Local API reference

GET /api/healthLocal service health and mode.
POST /api/chatServer-side OpenAI Responses API; requires a private dedicated API key.
GET /api/usageSummary and latest usage events.
POST /api/usageRecord validated usage; duplicate request IDs are idempotent.
GET /api/tasks · POST /api/tasksList or save local planned tasks.

Example request

fetch('/api/usage', {
  method: 'POST',
  headers: { 'content-type': 'application/json' },
  body: JSON.stringify({
    requestId: crypto.randomUUID(),
    productCode: 'mayzicai-studio',
    serviceCode: 'demo',
    quantity: 1,
    unit: 'request',
    estimatedCostMinor: 0
  })
})

Verified Auto-Cycle

Local Ollama proposes a small patch. The fixed isolated verifier checks it, and the host applies it only when every gate passes and source hashes remain unchanged. This does not run AI-generated shell commands, push Git commits, or deploy to hosting.

Auto-apply is enabled in the local server. A failed verification or stale source hash blocks application. No Git push or live deployment occurs.
Production gaps
Authentication, account isolation, rate limiting, migrations, provider integrations, pricing rules, billing, permissions, and security review are not implemented. Do not use for real customer data or payments.
